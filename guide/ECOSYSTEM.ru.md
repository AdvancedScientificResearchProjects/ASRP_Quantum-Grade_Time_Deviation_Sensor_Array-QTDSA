# Экосистема ASRP, патенты, безопасность и контакты

## Связь с патентом

**Заявки на патент QTDSA нет.** README называет исследование поисковым. QTDSA — аппаратно-метрологическая концепция и,
в отличие от исследований гиперболического поля и кластера сознания, не привязана ни к одной существующей патентной заявке
ASRP (Kazpatent). README не заявляет для неё патентной основы, поэтому здесь её тоже нет.

**Заявка — это не выданный патент.** Патентные строки ниже — заявки, перечисленные только как контекст экосистемы.
Ни одна из них не является патентной основой QTDSA.

## Классификация данных

README определяет четыре уровня. Ни один из них этому репозиторию не назначен.

| Уровень | Доступ | Маркировка | Описание |
|---|---|---|---|
| **PUBLIC** | Открытый | ЗЕЛЁНЫЙ (GREEN) | Общая информация |
| **RESEARCH** | Только команда | ЖЁЛТЫЙ (YELLOW) | Исследовательские данные |
| **RESTRICTED** | Основная команда | КРАСНЫЙ (RED) | Конфиденциальный анализ |
| **INTERNAL** | Только директор | ЧЁРНЫЙ (BLACK) | Только обзор уровня директора |

Какой уровень относится к этому README, — открытый вопрос (см. [EVIDENCE](EVIDENCE.ru.md#открытые-вопросы), пункт 4).
