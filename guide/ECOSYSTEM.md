# ASRP ecosystem, patents, security and contact

## Patent connection

**No QTDSA patent application exists.** The README says the study is exploratory. QTDSA is a hardware and metrology
concept and, unlike the Hyperbolic Field and consciousness-cluster studies, is not tied to any existing ASRP Kazpatent
filing. The README claims no patent basis for it, so none is asserted here.

**An application is not a granted patent.** The patent rows below are applications listed for ecosystem context
only. None of them is the IP basis for QTDSA.
